 🌿 FoodBridge — Zero Waste, Maximum Impact

FoodBridge is a smart web-based platform designed to reduce food waste by connecting food donors (restaurants, cafes, households) with receivers (NGOs, shelters, communities). It uses a clean UI and simulated AI matching to ensure surplus food reaches people in need efficiently.

---

🚀 Features

🔐 Authentication

- Login & Registration system
- Role-based access:
  - 🏪 Donor
  - 🤲 Receiver (NGO)
  - ⚙️ Admin

---

📊 Dashboard

- Real-time statistics:
  - Food donated
  - Meals served
  - CO₂ saved
- Weekly activity chart
- Nearby activity map (UI simulation)

---

➕ Donation Module (Donor)

- Add surplus food details:
  - Food name, category, quantity
  - Expiry time
  - Pickup location
- Upload food images (UI placeholder)
- AI-based NGO matching preview

---

🔍 Browse Food (Receiver)

- View available food donations
- Filter by:
  - Category
  - Distance
  - Urgency
- Request pickup instantly

---

🎯 AI Matching System

- Smart matching based on:
  - Location
  - Food type
  - Urgency
  - NGO capacity
- Match score (%) displayed
- Quick confirmation system

---

📦 Requests & Tracking

- Track:
  - Pending
  - Matched
  - Pickup
  - Completed requests
- Status indicators with color coding

---

🔔 Notifications

- Real-time alerts:
  - Match found
  - Pickup scheduled
  - Expiry warnings
- Multiple channels (UI simulation):
  - Email
  - SMS
  - Push notifications

---

👤 Profile

- Organization details
- Impact statistics
- Ratings & achievements

---

⚙️ Admin Panel

- Manage users
- Monitor platform activity
- View reports:
  - Total donations
  - Meals served
  - CO₂ reduction

---

🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript
- Design: Custom CSS (no frameworks)
- Fonts: Google Fonts (Sora, Space Mono)
- Architecture: Single Page Application (SPA using JS state)

---

🧠 Key Concepts Used

- State management in JavaScript
- Dynamic rendering
- Component-based UI (manual)
- Event handling
- Responsive layout (Flexbox + Grid)
